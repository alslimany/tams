# Videcom Airline Integration – Commands & Patterns

## API Endpoint
`https://customer2.videcom.com/{airline}/vars/public/webservices/VRSXMLWebservice3.asmx?op=RunVRSCommand`

## Authentication
Token generated by Videcom from (sine code + IP + password). Store in `tenant_providers.credentials` (JSON: `{token, base_url, airline_code, sine, ...}`).

## Command Syntax
- Chain commands with `^`
- Request XML response with `~x`
- End PNR‑modifying chain with `*R~x`
- Start session with `I^` (uppercase I)

## Key Commands
- Availability one‑way: `A{date}{origin}{dest}[SalesCity=...,SingleSeg=s,...]`
- Availability return: chain two `SingleSeg=r` commands.
- Price only (no hold): `i^-{paxString}^{segment1}^{segment2}...^FG^FS1^*r~x`
  - Use `QQ` in segment instead of `NN` to avoid hold.
- Book & issue: `I^-{pax}^9-1M*{phone}^9-1E*{email}^0{airline}{flt}{class}{date}{orig}{dest}NN{seats}...^FG^FS1^MI-{invoiceRef}^EZT*R^EZRE^*R~x`
- Void ticket: `EZV*R`
- Refund: `RM{amount}` or `RC...` (airline‑specific overrides)

## Round‑Trip Pricing Rule
- If outbound and return airline are the **same**, use combined command (two segments) to get return price (may include discount).
- If different airlines, price return as one‑way independently.

## Response Parsing (XML)
- `<PNR RLOC="...">`
- `<Itinerary><Itin>`: flight segments, status (`HK` = confirmed)
- `<FareQuote><FareStore FSID="Total">`: grand total
- `<Tickets><TKT>`: ticket numbers and coupons
- `<Payments><FOP>`: payment method and reference
- `<FareTax><PaxTax>`: detailed taxes

## Commission
- Domestic / international rates stored in `tenant_providers.commission_domestic` / `commission_international`.
- Calculated on `net_fare` (before taxes).

## Provider Factory
- `ProviderFactory::make($providerType, $airlineCode, $tenantId)` returns an instance of `AirlineProviderInterface`.
- Each airline (Oya, Medsky, Buraq) extends `BaseVidecomAirline`.

## Route Availability Cache (global)
- Table `route_availability_cache` in central DB tracks which airlines have flights on (origin, destination).
- Used to skip providers with no flights, reducing API calls.
